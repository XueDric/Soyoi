# Visual Assets

`backgrounds/craft_club_room.png` was generated with OpenAI ImageGen on 2026-09-07 for this
student project. It depicts an original school handicraft club room and contains no logos or text.

The background is designed for a 16:9 battle screen. UI labels, cards, characters, enemies, and
interaction states are rendered by pygame so they remain editable in source code.

## Soyoi reference art

The following files were extracted from the locally installed `SoyoiMod-Rebuild` resource pack
for this course demo. Only the assets needed by the first playable hand are included:

- `characters/soyoi_idle.webp`: Soyoi's original combat idle illustration.
- `card_art/strike_soyoi.webp`: Strike portrait.
- `card_art/soyoi_reward_001.webp`: Perler Pattern / 拼豆弹射 portrait.
- `card_art/soyoi_reward_013.webp`: Continuous Sanding / 连续打磨 portrait.
- `card_art/soyoi_reward_016.webp`: Layered Reinforcement / 叠贴加固 portrait.
- `card_art/soyoi_reward_026.webp`: Showcase / 交付展示 portrait.

The scrapbook-style HUD and card frames are newly drawn with pygame primitives. The external UI
reference was used only for layout and visual language; its characters, enemies, icons, and card
illustrations were not copied into the project.
