# Python 卡牌创作工坊

一个用 Python 写的卡牌游戏 Demo。玩家可以自己做卡牌，再进对局验证效果。

对战部分用的是常见的回合制牌组玩法(抽牌，费用，格挡，状态)，
项目重点放在创作端：
玩家不用改代码，填一张表单就能造出一张牌，保存成 JSON 后直接进游戏试打。

```
填表造牌(Tkinter)  →  存成 JSON  →  加进卡组  →  对局验证(Pygame)
```

## 快速开始

```powershell
# 1. 安装依赖(只有战斗界面需要 pygame-ce；造牌界面用的是 Python 自带的 tkinter)
python -m pip install -e .

# 2. 打开造牌界面
python main.py

# 3. 造完牌之后，进对局试打(会用你在创作端选中的那副卡组)
python main.py --battle

# 4. 想挑对手？先看清单，再指定(编号或中文名都行)
python main.py --enemies
python main.py --battle --enemy cultist

# 5. 想指定用哪副卡组？
python main.py --battle --deck 我的卡组
```

### 卡组：造完牌就有一副能打的牌组

以前对局固定用“角色起始牌组 + 自制卡”，现在改成**可以建多副，各自取名**:

| 造牌端 ④ 卡组面板 | 干什么 |
| --- | --- |
| 新建卡组 | 底子就是 **4 张打击 + 4 张防御**(示例卡组是内置的，只读) |
| 保存卡组 | 把当前卡组(连同名字)存下来，这就是“保存键” |
| 另存为 | 留着原来那副，再存一份新的 |
| 加入该卡组 / 移出 | 把选中这张牌在卡组里的份数改成“份数”框里的数字，或从卡组里拿掉(卡牌文件还在) |

- **份数框就是真实份数**：选中列表里的一张牌，框里显示的就是它现在在卡组里放了几份；
  改成几就放几份(不是再加几份)。保存新牌时也照这个数字进卡组(默认 1 份)。
- **保存卡牌时顺手入组**：造完一张牌点“保存卡牌”，它自动进当前卡组，马上能打；
  已经在卡组里的牌改数值重存，份数不变。
- **选中的那副就是对局用的**：下拉框选中哪副，战斗端就用哪副(也可以 `--deck 名字` 指定)。
- **示例卡组**：内置的一副(角色起始牌组 + 8 张奖励牌)，可以先打一局，也可以照着配。
- **已存的卡随时能改**：列表里点一张卡 → “载入表单”改数值再保存，或者加入 / 移出卡组。
- 老版本的 `user_cards/test_deck.json` 第一次启动时自动升级成“我的卡组”。

### 两个客户端怎么启动

程序有两个界面，都从 `源代码/` 目录启动：

| 客户端 | 干什么 | 命令 | Windows 双击 |
| --- | --- | --- | --- |
| **造牌端**(Tkinter) | 填表造卡，保存，加入卡组 | `python main.py` | `启动创作端.bat` |
| **战斗端**(Pygame) | 拿自制卡打一场，验证效果 | `python main.py --battle` | `启动战斗端.bat` |

运行说明：

- **在 `源代码/` 目录运行**，入口是 `main.py`.
- **造牌端用 tkinter**(Python 自带)；**战斗端用 pygame-ce**(`python -m pip install -e .`).
- 不开窗口也能验证：`python main.py --check`(读卡 → 开一局 → 打印手牌)。
- `--demo` / `--list` / `--check` 只用标准库，装了 Python 3.10+ 就能跑。

不想开窗口也能用：

```powershell
python main.py --demo       # 生成一张示例卡"重击"
python main.py --list       # 列出已经保存的卡牌
python main.py --check      # 自检：读卡 -> 开一局 -> 看手牌，确认连接是通的
python main.py --enemies    # 列出可选敌人
```

## 敌人

敌人的下回合意图会提前显示，玩家可以根据意图安排出牌。

**意图只有三种**:`攻击` / `防御`(套格挡)/ `强化`(加力量)。
原游戏里“上毒，塞伤口，偷东西”这类花样，我们都做成**挂在攻击上的附加效果**,
不新增意图类型 —— 比如“打你 4 点两段，同时塞 2 张废牌给你”。

| 敌人 | 生命 | 套路 | 应对 |
| --- | --- | --- | --- |
| 颚虫 | 44 | 啃咬 11 → 硬化(防御 6)→ 甩尾 7 | 它硬化那回合正好攒牌 |
| 邪教徒 | 52 | 第 1 回合“仪式”(强化 +3)，之后一直打 | 必须速杀，拖越久越痛 |
| 摸金校尉 | 46 | 偷窃 10 → 扒手 5×2 → 逃跑(防御 18)→ 烟雾弹(攻击 + 虚弱) | 逃跑回合别浪费输出 |
| 铁皮哨卫 | 60 | 血量过半前蓄力重击，过半后改成 8×4 连击 | 趁它重击前把血打下去 |
| 废料巨像(Boss) | 140 | 一阶段挥砸 / 上发条 / 铁壳；二阶段碾压 6×3，灌铁屑(顺带塞牌)，重锤 18 | 算好阶段血量，备好格挡 |

每只怪的形状和配色写在敌人类里，界面按数据绘制。
细节见 [`文档/程序说明.md`](文档/程序说明.md) 的 3.6 节。

## 用脚本加敌人(不改代码)

`content/enemy_scripts/` 里每个 `.txt` 就是一只敌人，写完立刻能打：

```text
# 井盖怪.txt
name = 井盖怪
hp = 40
flavor = 它把自己拧在井口上，谁也不许过。
appearance = robot / 120,120,110 / 218,91,75

attack 9                  # 攻击 9
defend 6                  # 套 6 点格挡
attack 7 effect=weak,1    # 攻击 7 并让你虚弱 1 层
attack 5 x2               # 攻击 5，打两段
buff 2                    # 强化：力量 +2
```

```powershell
python main.py --scripts-list                    # 看脚本里有哪些敌人(含报错定位)
python main.py --battle --scripts my_scripts     # 加载自己的脚本目录
python main.py --battle --enemy 井盖怪           # 直接打脚本敌人
```

仓库自带三个示例脚本(井盖怪 / 打卡机 / 抽奖转盘)，随游戏一起加载。
脚本写错时给出文件名，行号和原因。格式说明见
[`content/enemy_scripts/README.md`](soyoi_game/content/enemy_scripts/README.md).

## 程序结构

```
main.py              入口：决定开哪个窗口
tkinter_ui.py        造牌的界面：表单，预览，保存，加入卡组
pygame_ui.py         打牌的界面：血量，手牌，敌人，点击出牌
card_creator.py      数据处理：检查输入，读写 JSON，把卡牌交给战斗框架
core/ combat/ soyoi/ content/    战斗框架：回合，能量，伤害结算，素材系统
```

| 文件 | 负责 | 不负责 |
| --- | --- | --- |
| `main.py` | 把命令行参数分给对应模块 | 不写界面，不做检查 |
| `tkinter_ui.py` | 画表单，读输入，把错误提示显示在出错那一行 | 不算数值，不写文件 |
| `pygame_ui.py` | 画战斗画面，把点击翻译成“我要出这张牌” | 不改血量，不算伤害 |
| `card_creator.py` | 校验，生成卡面文字，读写 JSON，拼起始牌组 | 不 import 界面库 |
| 战斗框架 | 回合流程，结算，胜负判定 | 不知道界面长什么样 |

详细说明见 [`文档/程序说明.md`](文档/程序说明.md)，里面列出了数据流和主要函数。

## 能造出什么样的卡

创作端支持 10 种效果，一张牌最多组合 3 条，按顺序结算：

| 效果 | 取值范围 | 效果 | 取值范围 |
| --- | --- | --- | --- |
| 造成伤害(可多段) | 1~999，最多 4 段 | 施加易伤 | 1~9 层 |
| 获得格挡 | 1~999 | 施加减弱 | 1~9 层 |
| 抽牌 | 1~5 张 | 获得力量 | 1~9 点 |
| 获得能量 | 1~3 点 | 回复生命 / 失去生命 | 1~999 |
| 生成素材 | — | | |

还能设置：名称，费用(0~3)，类型(攻击/技能/能力/**素材**)，目标(自己/单个敌人/所有敌人)，
稀有度，关键字(消耗/保留)。

### 卡面图片：给自己的牌配一张插画

“③ 卡面预览”那一行有 **卡面图片**：点“选择图片…”挑一张自己的图(png / jpg / webp / gif / bmp),
预览里立刻能看到成品；点“保存卡牌”时，这张图会被**复制**进 `user_cards/art/`,
原图挪走，改名，换台电脑都不影响。进对局后，战斗端画牌时用的就是这张图。

**没有现成的图？** 挑图对话框默认开在 `assets/card_art/`，里面 45 张卡面(`.webp`)都能直接选；
自己找的图(png / jpg / webp / gif / bmp)也可以从别处挑。

- 图片跟着卡牌编号存在 `user_cards/art/<编号>.<后缀>`，所以 JSON 里只记相对路径(`"art/<编号>.png"`),
  不记原图路径 —— 卡牌目录整个复制走，卡面也不会丢。
- 换图会自动删掉旧后缀的那张；点“清除”再保存，或者删掉这张牌，`art/` 里那张也会一起删掉。
- 挑图时会先读一次：读不出来的图(改了后缀的假图片，坏文件)当场提示换一张，不会存下一个永远空白的卡面。
- 没设插画的牌，战斗端还是老样子画占位卡面，不影响数值和结算。

### 素材牌：造一件能装到别的牌上的“装备”

“生成素材”的牌打完后，素材以**一张素材牌的形式进入手牌**:

```
打出"拼豆弹射"           手牌里多一张"拼豆色包"
   ↓                            ↓
造成 7 点伤害          点它 → 再点一张手牌 → 素材装到那张牌上(3 个槽)
```

- 素材牌**不能打出**，它是装备：不花能量，也不占出牌次数。
- 三个槽满了时与轮到的那个槽**合料**(诅咒素材不能合料)。
- 装了素材的牌再打出去时，素材效果才结算(比如“拼豆色包”额外造成 3 点伤害)。
- **类别决定素材是否被消耗**：一次性素材结算完从槽位消失，普通 / 永久 / 诅咒素材保留。
- 起始遗物“酱油部徽章”每回合也是发一张随机素材牌，装到哪张牌上由你决定。
- 想造自己的素材，就在创作端把类型选成“素材”：填效果，数值和类别
  (一次性 / 普通 / 永久 / 诅咒)，造出来的素材会跟着当前卡组进对局。

勾了“消耗”的牌打出后进消耗堆，勾了“保留”的牌回合结束留在手上(和不勾的牌对比一下就看得出来)。

## 卡牌存成什么样

```
user_cards/
├── user_20260914134324787462.json   # 一张卡 = 一个 JSON 文件
└── art/                             # 卡面图片(user_cards/art/<编号>.<后缀>)

user_decks/
├── deck_20260923215526767635.json   # 一副卡组 = 一个 JSON：{"卡牌编号": 份数}
└── selected.json                    # 记当前对局用哪一副({"deck_id": "..."})
```

```json
{
  "schema_version": 1,
  "card_id": "user_20260914134324787462",
  "title": "重击",
  "cost": 2,
  "card_type": "attack",
  "target": "enemy",
  "keywords": [],
  "text": "造成12点伤害.",
  "effects": [{ "op": "damage", "value": 12, "hits": 1 }],
  "art": "art/user_20260914134324787462.png"
}
```

(`art` 是玩家设的卡面图片；没设就是空串，战斗端画占位卡面。)

素材牌用同一套文件格式，只是 `card_type` 是 `material`,`rarity` 那格存的是素材类别：

```json
{
  "schema_version": 1,
  "card_id": "sparkle_sticker",
  "title": "亮片贴纸",
  "cost": 0,
  "card_type": "material",
  "rarity": "normal",
  "target": "self",
  "keywords": [],
  "text": "承载牌打出后额外造成3点伤害.",
  "effects": [{ "op": "material_damage", "value": 3, "hits": 1 }]
}
```

几条设计上的选择：

- **存的是配置，不是代码**。玩家改得动卡牌，改不动伤害公式和回合流程。
- **读回来会再检查一遍**。手改 JSON 把伤害写成 99999，或者把 `art` 指到卡牌目录外面，都会被拒绝。
- **坏文件跳过并提示原因**，其余卡牌照常加载。
- **同名不覆盖**：第二张“重击”自动加 `-2` 后缀。
- **图片跟着卡牌走**：挑的图会复制进 `user_cards/art/`，不依赖原图还在不在。

## 操作方式

**造牌界面**：填完表单点“保存卡牌”(会顺手加进当前卡组)；
右侧列表选中一张卡可以“载入表单”(改数值)，“加入该卡组”，“移出”，“删除卡牌”；
下面的卡组面板可以“新建卡组 / 保存卡组 / 另存为 / 删除卡组”，
**下拉框里选中哪副，对局就用哪副**。类型选“素材”时，费用/目标/关键字会自动锁上，
第三个下拉框从“稀有度”变成“素材类别”。

**战斗界面**：点手牌选中，再点敌人打出攻击牌；技能牌点一下直接结算；
**点一张素材牌，再点一张手牌，就把素材加工上去了**(按 `Esc` 或点空白处取消)；
点右上角“结束回合”；点旁边的“换敌人”弹出**选择对手浮层**——列出全部 8 只怪(编号 / 名字 /
生命 / 普通·BOSS·脚本)，点一行就换到那只，牌组不变，正在打的那只会标上“正在打”，
点面板外面或按 `Esc` 取消(按 `E` 直接开关这个浮层)；
数字键 1~9 也可以选牌，回车/空格结束回合，`R` 重开。
标题栏位置会显示这一局用的是哪副卡组，一共几张。

手牌里没有其他牌时，带“生成素材”的牌不可打出。
