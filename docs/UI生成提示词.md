# 所依卡牌游戏 UI 生成提示词

下面这段提示词可直接交给 UI 设计模型、图像生成模型或代码生成模型。若只生成效果图，
忽略最后的 pygame 实现要求即可。

## 提示词

你是一名擅长 2D 卡牌游戏的 UI/UX 设计师兼 pygame 开发者。请为一款面向大学课程
答辩的中文单机卡牌战斗 Demo 设计并实现一套完整战斗界面。游戏名为《所依：酱油部
作战》，核心玩法是回合制出牌、3 点能量、敌人意图和“三槽素材加工”。可以借鉴成熟
卡牌肉鸽的信息层级，但不得复制任何现有游戏的具体界面、图标、卡框或美术。

画面采用 1280×720、16:9 横屏参考分辨率，并支持窗口等比例缩放和黑边适配。背景是
明亮的校园手作社团教室，包含工作台、拼豆、毛毡、吧唧机和收纳盒；中央区域保持简洁，
用于放置敌人。整体使用冷青色、珊瑚红、炭黑、纸张白和少量明黄组成的多色调色板，
营造“认真赶制社团周边”的氛围。不要使用大面积紫色渐变、发光圆球、营销网页式布局，
也不要把主要内容放进层层嵌套的卡片容器。

界面布局如下：顶部是一条半透明状态栏，左侧显示品牌“SOYOI / 酱油部作战”，中部
显示当前回合和操作状态，右侧是醒目的“结束回合”按钮。左侧中部为玩家状态区，显示
所依头像、姓名、72 点最大生命、格挡和当前能量。右侧中部为敌人区，显示原创的“废料怪”、
生命条、状态和下一回合意图。画面底部是手牌区，默认展示 5 张牌；卡牌过多时允许轻微
横向重叠，但标题、费用和关键数值必须保持可读，悬停或选中时卡牌上移且不改变整体布局。
左下和右下显示抽牌堆、弃牌堆、消耗堆数量。

卡牌固定为紧凑竖版，圆角不超过 8 像素。攻击牌用珊瑚红，技能牌用青绿色，能力牌用
明黄棕色；左上角圆形费用标记，顶部为卡名，中部为类型和效果文字，底部显示三个素材槽。
空槽使用描边圆圈，已加工槽使用不同颜色的实心圆点。稀有度使用 1 至 3 个小型金色标记，
不要依赖颜色作为唯一信息。所有中文必须完整显示，不能溢出、遮挡或使用过小字号。

交互流程必须清晰：点击技能牌后立即结算；点击攻击牌后进入目标选择状态，再点击敌人
完成出牌；能量不足时给出明确提示；伤害、治疗和格挡以短暂上浮数字反馈；敌人受击时
短暂闪白；回合结束后执行敌人意图并补充新手牌；胜利或失败时显示遮罩、结果标题和
“重新开始”按钮。支持鼠标操作，同时支持数字键选择手牌、回车或空格结束回合、Esc 退出。

若生成代码，请使用 Python 3.10+ 与 pygame-ce 2.5.7，不引入其他复杂 UI 框架。复用现有
`CombatState`、`Player`、`Enemy`、`Card` 和 `setup_soyoi_combat()`，UI 层只能调用战斗
接口，不能直接修改生命、能量或牌堆。采用“事件处理 → 状态更新 → 绘制 → flip”的单一
主循环，移动或动画使用 delta time。将界面绘制到 1280×720 的虚拟画布后再等比缩放，
并正确反算鼠标坐标。输出应包含可直接运行的 pygame 源码、资源路径说明、无窗口截图模式
以及覆盖渲染、攻击选目标、技能直接结算和结束回合的基础测试。
